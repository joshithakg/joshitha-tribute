## Joshitha's Books

Joshitha's Books is a website to shop books that showcases modern website design ideas that could also be mobile friendly. The intention of this project is to only demonstrate the website design not the functionalities. This is implemented using HTML and CSS along with minimal Java script code. 

### What the Project Is and What It Does

Joshitha's Books demonstrates the following book store features with modern design ideas 

Book store features:

- User Login
- Browse books by Categories
- Latest Events like Halloween specifc
- Best sellers
- Book Reviews
- Shopping Cart
- Search, Newsletter, Feedback

Design features:

- Navigation bar at the top with links to other sections
- Innovative Login form that appears as a Light weight popup but actually driven by css styles
- Sliding Views that scrolls automically that is appealing
- Mouse hover changes to grab user attention
- Swiper controls with sliding and wrapping object for an appealing look
- Eye catching Icons and images to convey the purpose easily
- Site Navigation links at the bottom
- Social Media icons to navigate to external websites
- Shopping cart page to demonstrate items added with quantity, each line item price and a total and a delete option for each 

### Why I Made This Project

I want to do a deep dive into website design and implement a modern website involving lots of CSS styles. Though I have learnt the basics of HTML and CSS in my studies and external course but I always thought that I need to explore more if I really want to build complete website. So, I decided to explore various tutorials, understand external open source CSS and Java script but I had to go through their documentation to understand how to use them 

###  How I Made It

First I wanted to be sure on what exactly I wanted to achieve in this project. It was the design of the website not the functionalitues. Hence I picked a simple functional book store. 

Next, I understood various CSS styling options available. I planned different sections of the web site, how each ones are linked and what design I want to apply on each. 

Also I explored open source CSS and java script available like the Swiper Js library. I studied their features and documentation on how to use.

Now, I started coding section by section. Writing HTML and CSS for each. Test them after every couple of lines of code. 

Finally I could achieve a full design and it looked really appealing and my confidence is much increased on HTML and CSS now. 

###  What I Struggled With

I ran into a few challenges while building this website:

- CSS styles are numerous and it is not easy to pick what we want. So I had to try and repeat many times before I could decide on the styles
- Rather than building a static page, I wanted to implement dynamic HTML where I can use <div> tags to control their behaviour through scripts.
- Consolidation and testing was a key.Though I developed each section separately I really needed to integrate them to avoid loose end, unhandled links etc.
  
### What I Learned

This project helped me understand a lot on CSS especially. I did a lot of styling, controlling the UI behaviour


### How to Play

- Download this repo as ZIP and extract locally 
- Launch the index.html on your favorite browser (Preferrably Google Chrome as I have externsively tested it).
